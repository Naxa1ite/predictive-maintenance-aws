# Data

`data/raw/` is git-ignored. `python ml/train.py` downloads the **AI4I 2020 Predictive Maintenance Dataset** automatically
(UCI, https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset, CC BY 4.0).

If the automatic download fails, download the ZIP from that page manually, extract the CSV and save it as
`data/raw/ai4i2020.csv`.

The dataset is **synthetic** (generated by the dataset authors to resemble industrial data); it is for academic
experimentation and is not a substitute for live industrial sensor measurements.
